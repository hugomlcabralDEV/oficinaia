Setup ~10 min

Nunca programou? Leia antes os primeiros passos: editor, terminal, API, chave e Python básico.

1. Gere sua chave grátis

Em aistudio.google.com/apikey › Create API key. A chave é como uma senha: não publique.

2. Crie seu repositório e clone

Clique em Use this template, dê o nome meu-agente-gemini e depois:

git clone https://github.com/SEU_USUARIO/meu-agente-gemini.git cd meu-agente-gemini git config --local user.name "Seu Nome" git config --local user.email "SEU_USUARIO@users.noreply.github.com"

3. Instale

python -m venv .venv .venv\Scripts\Activate.ps1 pip install -r requirements.txt copy .env.example .env
python3 -m venv .venv source .venv/bin/activate pip install -r requirements.txt cp .env.example .env

4. Cole a chave no .env e teste

GEMINI_API_KEY=cole_sua_chave_aqui GEMINI_MODEL=gemini-3.8-flash
python 00_setup/verificar_ambiente.py
💾 Ao fim de cada módulo: git add . → git commit -m "módulo X" → git push

Módulo 1 · Primeira chamada

Falar com o Gemini, dar memória à conversa e ver uma alucinação acontecer.

from google import genai cliente = genai.Client(api_key="SUA_CHAVE") # no projeto, a chave vem do .env interaction = cliente.interactions.create( model="gemini-3.8-flash", input="Explique o que é uma API em 3 frases.", ) print(interaction.output_text)
